## Security and architecture checks

- [x] Model output is untrusted: tool arguments are validated as JSON objects before execution, invalid arguments become tool results, never a panic
- [x] Tool execution stays in RepoSurgeon (`RunToolLoop`); the provider is never asked to execute code or read files
- [x] The provider key is only ever read from configuration, never returned, logged or written to error bodies (`providerErrorFor` returns mapped codes)
- [x] The probe prompt is fixed server-side and contains no repository content, so the endpoint cannot exfiltrate source
- [x] Probe/status require `credential.admin` and are audited
- [x] Requests are validated (model, messages, effort, sizes) before any provider call
- [x] No production stub: the StepFun client is the real implementation; the fake provider is used only by tests

## Fixes made during the milestone (real bugs found and corrected)

1. `isTimeout` handling: client timeouts surfaced as raw transport errors; they now map to `ErrProviderTimeout` (504).
2. `ProviderError` could be constructed without its sentinel, so `errors.Is` matching failed; `NewProviderError` now derives it from the status.
3. The gateway status/probe handlers initially returned 404 because the routes were registered only when the gateway existed while the server was built before the gateway — resolved by constructing the gateway before the server.
4. The probe endpoint did not audit the "no provider configured" path; it now records `model.probe_failed`.

## Remaining risks / limitations

- No live StepFun account was used in this milestone, so the 200-path probe against the real provider is exercised only against the fake provider and a local httptest server. A live probe requires `STEPFUN_API_KEY` and is a documented deployment step.
- The `POST /model/probe` prompt is fixed; richer model interactions (plan generation, tool-call conversations) arrive with M08–M09 behind the same gateway.
- Token/cost accounting is surfaced in responses and audit records; per-run usage persistence lands with M06 runs.
