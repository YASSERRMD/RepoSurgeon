## Fixes made during the milestone (real bugs found and corrected)

1. The migration file was created with an invalid name (`0012_repo_index.sql.up.sql`); renamed to the supported `NNNN_name.up.sql` shape.
2. `upsertFile` initially emitted an UPDATE without an INSERT path, so new files were never indexed; rewritten as an INSERT … ON CONFLICT with a deterministic id.
3. Handler tests exposed a nil-pool panic in `Rebuild`; the index now reports `Available()` and handlers return 503 instead of crashing.
4. `writeIndexUnavailable`/`writeContextUnavailable` passed a nil request into `WriteError`, panicking; both now take the request.

## Remaining risks / limitations

- Context manifests are persisted in-process in this milestone; the durable `context_manifests`/`context_provenance` tables are migrated and exercised by the index tests, but the API store moves to them in the persistence follow-up.
- Needle-in-large-repo benchmarks (32k/128k/256k windows) are structured by the budget tests but the M17 laboratory runs the full benchmark.
- Symbol extraction is regex-based for Go/Python/TypeScript; a language server remains a documented future option.
