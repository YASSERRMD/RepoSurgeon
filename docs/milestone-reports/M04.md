## Security and architecture checks

- [x] Webhook signature failures are rejected with 401 and record nothing
- [x] Replayed delivery IDs return 200 `duplicate` and never mutate state twice
- [x] Cross-organization installation/repo access is denied (404, not 403, to avoid confirming existence)
- [x] The GitHub App private key lives only in the API process; the runner never receives it
- [x] Issue bodies are stored and returned as untrusted data with an explicit body hash
- [x] No webhook path can start a run; task creation remains an explicit authorized action
- [x] The adapter never infers identity from Git configuration
- [x] OpenAPI contract and client drift-free; migrations reversible

## Fixes made during the milestone (real bugs found and corrected)

1. `doJSON` passed a nil context into `http.NewRequestWithContext`, so every GitHub request failed — fixed to `context.Background()` with the caller context threaded through.
2. `handleGitHubWebhook` was wrapped by the session middleware, which rejected every signature-valid webhook with 401; webhooks now bypass session auth entirely.
3. A replayed but authentic delivery was answered 401; it now returns 200 `duplicate` (GitHub treats non-2xx as retryable).
4. Imported issues carried no `body_hash`, so staleness detection was impossible; the handler now computes it.
5. Test fakes initially used concrete store types, blocking handler tests; the GitHub services now depend on interfaces.

## Remaining risks / limitations

- **No live GitHub App was connected in this milestone**, so the real handshake (installation callback, live REST calls) is exercised only against a fake GitHub server. Live verification requires a GitHub App with the documented least-privilege permissions and is recorded as the deployment prerequisite for M13.
- ETag/conditional-request caching and rate-limit backoff are modelled (`ETag` column, `RetryAfter` parsing) but not yet driven by a rescan loop; that lands with M08 context building.
- Webhook events are recorded but do not yet enqueue sync jobs; the queue arrives with M06.
