## Fixes made during the milestone (real bugs found and corrected)

1. The parser did not strip git's `a/`/`b/` prefixes, so patches targeted nonexistent paths.
2. Deletions were reported but never performed.
3. Hunks applied positionally without verifying context, so a stale diff corrupted files; every context and removed line is now compared and a mismatch returns `diff_context_mismatch` (409).
4. Patch engine errors surfaced as 500s; they now map to 400/403/409/413 with stable codes.
5. New-file hunks (`@@ -0,0 +1,N @@`) were rejected.

## Remaining risks / limitations

- Checkpoints are recorded in-process; the durable `patch_attempts` table lands with the M11 persistence follow-up.
- The physical restore is verified through hashes; the runner-side rollback command arrives with M11.
- Diff viewing UI is covered by the M14 web workbench; the M10 surface returns the real `git diff HEAD` payload.
