## Fixes made during the milestone (real bugs found and corrected)

1. `safePath` did not resolve symlinks, so a link inside the workspace could point outside it — caught by the adversarial test; it now resolves the deepest existing ancestor and re-checks the prefix.
2. Approval errors surfaced as generic 500s; they now map to 404/409 with stable codes.
3. The typed-client `JsonOf` helper resolved every alias to `never` (it indexed `responses` instead of the per-method operations); fixed so the tool/approval types are real.

## Remaining risks / limitations

- `apply_patch`, `restore_checkpoint` and the GitHub mutations are catalogued and permission-gated but their implementations arrive with M10/M13; the executor refuses them explicitly rather than pretending.
- Namespace-level default-deny egress for sandboxed commands lands with the Linux runner image in M07's follow-up work; the process-level confinement (allowlist, bounded output/timeout, no host shell) is enforced now.
- Approval records are in-process; the durable table is part of the M07 persistence follow-up.
