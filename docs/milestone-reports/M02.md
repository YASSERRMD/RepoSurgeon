## Security and architecture checks

- [x] Authentication matrix positive/negative across every protected route
- [x] Credential values never appear in responses, logs or browser storage (client stores only the CSRF token in memory and the active org id in localStorage)
- [x] Brute force: per-email failure counter with lockout (5 failures / 15 minutes), identical responses for unknown accounts and wrong passwords
- [x] Session fixation: a fresh token and CSRF token are issued on every login and refresh; the presented token is revoked on rotation
- [x] IDOR: every query is organization scoped; cross-tenant credential and project reads return 404
- [x] Permission denials are audited and enforced server-side (UI gating is convenience only)
- [x] `RS_CREDENTIAL_KEK` is required outside the test environment; compose refuses to start without it
- [x] OpenAPI/client drift and migrations up/down verified

## Fixes made during the milestone (real bugs found and corrected)

1. `secrets.EncryptSecret` sealed the value with a nonce it discarded, so every decryption failed — caught by the round-trip test; the value is now sealed with the returned nonce.
2. Credential handlers performed no permission check, so a viewer could create credentials — caught by `TestCredentialAccessRequiresPermission`; `credential.admin`/`member.admin`/`project.read` are now enforced in every privileged handler and denials are audited.
3. `/api/v1/auth/refresh` was classified as a public path, so it ran without the session middleware and always returned 401.
4. `Audit.Append` used 10 placeholders for 9 columns (fixed in M01, regression-tested here through the HTTP smoke).
5. Argon2id parameters and cookie flags needed explicit gosec justifications with reasoning recorded in comments.

## Remaining risks / limitations

- The M01 development subject resolver still exists for servers without M02 services wired; production requests receive 401 (tested), and M03 removes the last callers.
- Credential verification (`last_verified_at`) has no live provider probe yet; the field is exposed honestly as “not verified”.
- OIDC is a documented path (identity `kind` supports `oidc`), but no provider is wired; that is deliberate for M02 and recorded rather than implied.
- Local Docker daemon unavailable on the development machine: image build and Compose smoke run in CI only.
