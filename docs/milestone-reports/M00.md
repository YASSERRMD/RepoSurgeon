## Review / recovery / remaining risks

Genuine failures found and fixed during the milestone (all with follow-up code changes):

1. Redaction produced malformed output for `Authorization:` headers and mis-redacted URL userinfo → replaced the replace-hook approach with explicit, ordered patterns plus a map-level sensitive-key rule; tests cover headers, JWTs, URL credentials, nested maps.
2. Router-generated plain-text 404/405 leaked the JSON error contract → replaced the response-rewriting middleware with a real method-aware router (`internal/api/router.go`) that emits canonical JSON with `Allow` headers.
3. Runner default timeout/output exceeded configured maxima → defaults are now clamped to the server maxima; tests cover both.
4. Migration integration tests coupled through a shared database → tests now own their version range, reset ledger rows and stale tables; verified idempotent across repeated local runs.

Remaining risks / limitations:

- **Local Docker unavailable**: image build, Compose smoke and Compose-hosted Playwright could not run on the development machine; they run in CI. If CI cannot run them either, M00 verification for those gates is incomplete by definition.
- The runner enforces process-level confinement; namespace/seccomp default-deny egress is scheduled for M07 with the Linux runner image (compose-level `internal: true` network already removes egress for the container).
- `main` is currently unprotected; branch protection with required checks is a documented prerequisite in the threat model and must be enabled before M13 merge automation.
