## Bugs found and fixed during the milestone

1. The `runs` table requires `project_id NOT NULL` with FK to `projects` — cross-tenant event test now seeds a project for the second organization.
2. The append-only trigger on `run_events` correctly rejects UPDATE/DELETE — the test now asserts the error instead of using `env.exec` (which treats any error as fatal).
3. Go 1.26.9 in `go.mod` and Dockerfiles carried stdlib vulnerability GO-2026-6809 (`crypto/x509`) — upgraded to 1.26.10 across `go.mod`, `go.sum`, `Dockerfile.api`, `Dockerfile.worker`, `Dockerfile.runner`. `govulncheck` now reports 0 vulnerabilities.

## Remaining risks / limitations

- The `dependency and container audit` check (govulncheck) was a pre-existing failure on main due to Go 1.26.9 stdlib vuln; resolved by the Go 1.26.10 upgrade.
