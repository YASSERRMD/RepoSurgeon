## Fixes made during the milestone (real bugs found and corrected)

1. `Queue.Enqueue` inserted an empty string for a nullable `run_id`, breaking the foreign key; empty references now become SQL NULL.
2. `Claim` scanned NULL `run_id` into a string and failed; it now scans into a nullable.
3. `Fail` passed an unused placeholder parameter that PostgreSQL could not type.
4. `Get` never selected `last_error`, so failure reasons were invisible.
5. `writeDomainError` mapped agent conflicts and `ErrRunNotFound` to generic 500s; they now return 409/404 as documented in the OpenAPI contract.
6. Webhook/run tests used blanket stubs that hid cross-tenant access; the fakes now model per-user organizations.

## Remaining risks / limitations

- The M06 handler is a pass-through: it drives the state machine and records durable facts but does not yet call the model, patch files or run checks — those arrive in M07–M12.
- Concurrency is proven with two workers in tests; a multi-worker load test under `-race` with a live PostgreSQL instance runs in CI.
- Run budgets (steps, duration, cost) are stored as limits and enforced from M12 onward.
